# Акторы, User Stories, Use Case

## Акторы

**Внешние:**
- Client — новый клиент банка
- KYC — процесс проверки личности клиента и оценки риска

**Внутренние:**
- Core Banking — центральная система учёта счетов, балансов и транзакций банка
- Notification Service — система уведомлений
- Kafka (Event Bus) — брокер сообщений для асинхронного взаимодействия между Onboarding Service, Core Banking и Notification Service

## User Stories

### [US-001] Открытие дебетового счёта для нового клиента банка
Как **Client**, я хочу открыть дебетовый счёт онлайн, чтобы не тратить время на визит в отделение банка.

Приоритет: Must | Статус: Draft

## Use Case: Открытие счёта

### Happy Path
1. [Client] нажал на кнопку "Открыть счёт"
2. [Система] предоставляет форму для заполнения данных
3. [Client] заполняет все необходимые поля и нажимает "Оформить заявку"
4. [Система] валидирует введённые данные
5. [Система] отправляет данные в KYC
6. [KYC] проверяет личность клиента и оценивает риски
7. [KYC] отправляет в систему статус "Approved"
8. [Система] принимает статус "Approved"
9. [Система] создаёт банковский счёт в Core Banking
10. [Система] отправляет уведомление клиенту со статусом "Approved"

### Альтернативные сценарии
- **4a.** Не все поля заполнены → система не пропускает заявку, просит заполнить обязательные поля (подсвечены красным)
- **5a.** KYC-сервис недоступен/не отвечает → клиент видит статус "заявка обрабатывается", результат придёт позже, заявка не теряется
- **7a.** KYC оценил клиента как высокорискованного, статус "Rejected" → заявка отклоняется, клиент уведомляется
- **7b.** KYC вернул статус "Manual Review" → заявка переходит в MANUAL_REVIEW, клиенту показывается "проверка занимает больше времени"
- **7c.** Заявка в MANUAL_REVIEW → менеджер вручную рассматривает через административный интерфейс, выставляет решение (approved/rejected)
- **9a.** Ошибка при создании счёта в Core Banking после успешного KYC → клиент не получает преждевременного уведомления об успехе; система гарантирует, что счёт будет создан ровно один раз
