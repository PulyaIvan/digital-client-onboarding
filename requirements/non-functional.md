# Нефункциональные требования

- **Производительность:** время ответа API не более 5000 мс
- **Доступность:** 99.9% в год (~8.76 часа простоя в год)
- **Security/Compliance:** чувствительные персональные данные (паспорт, СНИЛС, ИНН, адреса) хранятся в БД в зашифрованном виде; сканы документов (паспорт, фото) не хранятся в основной БД — только ссылка на защищённое хранилище (vault)
- **Наблюдаемость/трассировка:** каждый запрос сопровождается идентификатором `X-Correlation-Id` (необязателен на входе, генерируется сервером, если клиент не передал; возвращается в заголовке ответа и в `ErrorResponse.requestId`) — позволяет найти в логах все шаги обработки одного конкретного HTTP-вызова, в т.ч. до того, как заявке присвоен `applicationId` (например, отказ на `POST /application` по валидации)
