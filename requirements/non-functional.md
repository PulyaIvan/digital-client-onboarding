# Нефункциональные требования

- **Производительность:** время ответа API не более 5000 мс
- **Доступность:** 99.9% в год (~8.76 часа простоя в год)
- **Security/Compliance:** чувствительные персональные данные (паспорт, СНИЛС, ИНН, адреса) хранятся в БД в зашифрованном виде; сканы документов (паспорт, фото) не хранятся в основной БД — только ссылка на защищённое хранилище (vault)
