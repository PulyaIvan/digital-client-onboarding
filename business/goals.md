# Бизнес-цели

**Дата:** 10.07.2026

## Цель
Автоматизированная система онбординга новых клиентов, которая:
- не требует участия человека в стандартном сценарии
- поддерживает требования регулятора по идентификации клиента (KYC)
- масштабируется на тысячи заявок
- предоставляет клиенту прозрачный статус на каждом этапе

Система рассматривает только сценарий онбординга нового клиента, для которого
верификация личности (KYC) и открытие первого счёта происходят в рамках одного процесса.

## Контекст
- **Что автоматизируем:** процесс онбординга нового клиента банка
- **Кому нужно:** банку, для внутреннего использования
- **Без системы:**
  - ручная обработка заявки долгая и ненадёжная
  - прозрачность статуса поддерживать сложнее
  - масштабирование на тысячи одновременных онбордингов невозможно
